# UCloud

> UCloud (优刻得科技股份有限公司, UCloud Technology Co., Ltd.) is a neutral Chinese cloud computing provider listed on the SSE STAR Market (688158). It offers compute (UHost, bare-metal UPHost, GPU), storage (UFile/US3 object storage, UDisk), networking (VPC, ULB load balancing, EIP, UDPN), Kubernetes (UK8S), databases (UDB MySQL/MongoDB/PostgreSQL, URedis), CDN, security, monitoring and AI infrastructure (Modelverse, Compshare), all managed through one Action-based Open API at api.ucloud.cn with signed requests, plus first-party SDKs, a CLI, and Terraform support. UCloud also operates an international arm at ucloud-global.com.

No provider-published llms.txt was found on docs.ucloud.cn or www.ucloud.cn (both hosts soft-200 every path); this file was generated by API Evangelist from the provider's published surfaces on 2026-07-21.

## APIs

- [UCloud Open API reference](https://docs.ucloud.cn/api): Action-based RPC API for all products; gateway https://api.ucloud.cn (public) and http://api.service.ucloud.cn (VPC-internal)
- [API quickstart & common parameters](https://docs.ucloud.cn/api/summary/public): Action/PublicKey/Signature parameters, RetCode envelope, platform error codes
- [Signature algorithm](https://docs.ucloud.cn/api/summary/signature): SHA1 request signing with PublicKey/PrivateKey
- [API gateway addresses](https://docs.ucloud.cn/api/summary/gateway): public and VPC-internal endpoints
- [API docs source (GitHub)](https://github.com/UCloudDoc-Team/api): markdown source of every product's API reference
- [Alarm webhook callbacks](https://docs.ucloud.cn/cloudwatch/use/webhook): Cloud Monitoring pushes alarm/recovery events to configured callback URLs
